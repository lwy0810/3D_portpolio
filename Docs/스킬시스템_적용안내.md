# 스킬 시스템 적용 안내

섬의궤적 스킬 알고리즘 설계를 코드와 CSV 로 구현한 결과물입니다.
딜레이는 **위키 공식** `Final Delay = floor(100 × BaseDelay / SPD)` 로 구현했고,
`SkillData.csv` 에 정수 `baseDelay` 컬럼을 두어 값을 표에서 조절합니다.

---

## 1. BaseDelay 표

`baseDelay` 는 행동이 정하고 `SPD` 는 유닛이 정합니다.

| 행동 | baseDelay | SPD 50 (Zangbi) | SPD 35 (Ubi) | SPD 30 (Gwanwoo) |
|---|---:|---:|---:|---:|
| 이동 · 아이템 · 행동불가 · 브레이크 | 10 | 20 | 28 | 33 |
| **통상공격 · 방어** | **20** | **40** | **57** | **66** |
| 크래프트 (중) | 25 | 50 | 71 | 83 |
| 크래프트 (고) | 30 | 60 | 85 | 100 |
| S크래프트 | 40 | 80 | 114 | 133 |

`ATB.xlsx` 실측 13건과 대조해 **13/13 일치**를 확인했습니다.
실측의 `ATB = 2000 / SPD` 는 이 식에서 `baseDelay = 20` 인 경우와 같습니다.
관계식은 `baseDelay = 20 × 배율` 입니다 (배율 0.5→10, 1.0→20, 1.25→25, 1.5→30, 2.0→40).

## 3. 씬 배치

`GameManager` 나 `StatusManager` 가 있는 오브젝트에 컴포넌트 두 개를 추가합니다.

| 컴포넌트 | 하는 일 |
|---|---|
| `SkillDataBase` | `Awake` 에서 CSV 3장 로드 + `DontDestroyOnLoad`. 씬마다 다시 읽지 않음 |
| `BattleFlow` | `ATQueue` 소유. 전투 진행 조율 |

`SkillDataBase` 는 `StatusManager` 와 **같은 오브젝트에 두는 것을 권장**합니다.
두 매니저가 함께 살아남아야 스킬 정의와 스탯이 같은 수명을 갖습니다.

콘솔에 다음 로그가 뜨면 정상입니다.


## 4. BattleManager 수정 지점

`BattleManager.cs` 는 입력과 연출만 담당하고, 순서와 판정은 `BattleFlow` 를 통합니다.

### 4-1. 삭제할 것

```csharp
private int attackIndex = 0;          // ATQueue 가 대체
public bool TurnOff { get; set; }     // 사용처 없음
void TrunMove() { ... }               // ATQueue.Push 가 대체
void MonsterTakeDmg(...) { ... }      // SkillResolver 가 대체
void MonsterAttack(...) { ... }       // BattleFlow.MonsterTurn 이 대체
void UnitDeath(...) { ... }           // BattleFlow.HandleDeaths 가 대체
```

`oriIndex` / `nextIndex` 는 **타깃 선택용**이므로 남겨둡니다.
단, 상한이 `2` 로 하드코딩되어 있으니 `Monsters.Count` 기준으로 바꿉니다.

```csharp
// 수정 전
if (nextIndex > 2) { nextIndex = 0; }
// 수정 후
if (nextIndex >= Monsters.Count) { nextIndex = 0; }
if (nextIndex < 0) { nextIndex = Monsters.Count - 1; }
```

### 4-3. Battle() — 전투 개시

```csharp
public void Battle()
{
    if (SceneManager.GetActiveScene().name != "CommandBattle") return;

    if (_commandActionPos == null)
    {
        GameObject bar = GameObject.Find("ActionBar");
        GameObject member = GameObject.Find("CommandMemberBar");
        if (bar == null || member == null)
        {
            Debug.LogError("[BattleManager] ActionBar / CommandMemberBar 를 찾을 수 없습니다.");
            return;
        }
        _commandActionPos = bar.transform;
        _commandBattlePos = member.transform;
    }

    // Speed 내림차순 1회 정렬 + attackIndex 순환을 제거하고 큐에 맡긴다
    _flow.OnQueueChanged += OnQueueChanged;
    _flow.OnSkillResolved += OnSkillResolved;
    _flow.OnUnitDown      += OnUnitDown;
    _flow.OnBattleEnd     += OnBattleEnd;

    _flow.Begin(Characters, Monsters);

    _battleMemberList = _createCommandBattleMemberSystem
        .CreateCommandBattleMember(_commandBattleMemberPrefab, _commandBattlePos);

    StartTurn();
}

void OnDestroy()
{
    SceneManager.sceneLoaded -= OnSceneLoaded;
    if (_flow != null)
    {
        _flow.OnQueueChanged  -= OnQueueChanged;
        _flow.OnSkillResolved -= OnSkillResolved;
        _flow.OnUnitDown      -= OnUnitDown;
        _flow.OnBattleEnd     -= OnBattleEnd;
    }
}
```

### 4-4. 턴 루프

```csharp
void StartTurn()
{
    if (!_flow.IsRunning) return;

    // 지속 피해 · 잔여 턴 처리. false 면 이 유닛은 행동하지 않고 넘어간다
    if (!_flow.BeginTurn())
    {
        StartTurn();                       // 다음 유닛
        return;
    }

    BattleUnit actor = _flow.Current;
    CameraMoveTo(actor);

    if (!actor.IsAlly)
    {
        StartCoroutine(MonsterTurnRoutine());
        return;
    }

    if (actor.Casting != null)             // 캐스트가 끝난 아츠
    {
        StartCoroutine(CastRoutine());
        return;
    }

    _commandState = CommandState.Select;   // 플레이어 입력 대기
}

IEnumerator MonsterTurnRoutine()
{
    SkillResult res = _flow.MonsterTurn();
    yield return StartCoroutine(PlayAction(res));
    StartTurn();
}

IEnumerator CastRoutine()
{
    BattleUnit target = CurrentTargetUnit();
    SkillResult res = _flow.ResolveCast(target);
    yield return StartCoroutine(PlayAction(res));
    StartTurn();
}
```

### 4-5. 통상공격 · 스킬 사용

```csharp
// CommandSelectController 의 Attack 분기
else if (_commandState == CommandState.Attack && IsAttack == false)
{
    IsAttack = true;

    SkillData skill = _pendingSkill != null
                      ? _pendingSkill                       // 스킬 선택 UI 에서 고른 것
                      : SkillDataBase.Instance.BasicAttack;  // 통상공격

    SkillResult res = _flow.Execute(skill, CurrentTargetUnit());

    if (res.Cancelled)
    {
        Debug.Log($"취소 : {res.CancelReason}");
        IsAttack = false;
        _commandState = CommandState.Select;
        return;
    }

    StartCoroutine(AfterAction(res));
}

IEnumerator AfterAction(SkillResult res)
{
    yield return StartCoroutine(PlayAction(res));
    IsAttack = false;
    _pendingSkill = null;
    StartTurn();
}

BattleUnit CurrentTargetUnit()
{
    if (nextIndex < 0 || nextIndex >= Monsters.Count) return null;
    return _flow.Queue.Find(Monsters[nextIndex]);
}
```

### 4-6. 연출 — 판정과 분리

핵심은 **판정이 이미 끝나 있다**는 점입니다. `res` 안에 데미지와 사망 여부가
확정되어 있으므로, 연출 중에 대상이 사라져도 값이 어긋나거나 예외가 나지 않습니다.

```csharp
IEnumerator PlayAction(SkillResult res)
{
    if (res == null || res.Cancelled) yield break;

    Unit actor = res.Actor.Unit;
    Animator anim = actor.GetComponent<Animator>();
    CharacterController cc = actor.GetComponent<CharacterController>();

    // 캐스트 예약 단계는 별도 연출
    if (res.WasCast)
    {
        yield return new WaitForSeconds(0.4f);
        yield break;
    }

    bool melee = res.Skill.Type == SkillType.Craft ||
                 res.Skill.Type == SkillType.Attack ||
                 res.Skill.Type == SkillType.SCraft;

    Vector3 startPos = actor.transform.position;

    if (melee && res.Targets.Count > 0 && res.Targets[0].Target.Transform != null)
    {
        Vector3 endPos = res.Targets[0].Target.Transform.position - new Vector3(0f, 0f, 2.5f);

        // 기존 버그 : (endPos - StartPos) 가 루프 불변이라 거리에 비례해 속도가 변했다
        // Lerp 로 목표 지점까지 정확히 이동한다
        yield return StartCoroutine(MoveTo(actor, cc, anim, startPos, endPos, 0.5f));
    }

    if (!string.IsNullOrEmpty(res.Skill.AnimTrigger) && anim != null)
        anim.SetTrigger(res.Skill.AnimTrigger);

    yield return new WaitForSeconds(1.0f);

    // 데미지 숫자 · 이펙트는 OnSkillResolved 구독자가 이미 처리했다
    for (int i = 0; i < res.Targets.Count; i++)
    {
        TargetResult tr = res.Targets[i];
        if (tr.Hit == HitResult.Miss || tr.Hit == HitResult.Evade)
            Debug.Log($"{tr.Target.Stat.Name} : {tr.Hit}");
    }

    if (melee)
        yield return StartCoroutine(MoveTo(actor, cc, anim, actor.transform.position, startPos, 0.5f));

    if (anim != null)
    {
        anim.SetBool("IsRun", false);
        anim.SetBool("IsWalk", false);
        anim.SetFloat("moveSpeed", 0f);
    }
    actor.transform.rotation = Quaternion.identity;

    yield return new WaitForSeconds(0.3f);
}

IEnumerator MoveTo(Unit unit, CharacterController cc, Animator anim,
                   Vector3 from, Vector3 to, float duration)
{
    if (anim != null) { anim.SetBool("IsRun", true); anim.SetFloat("moveSpeed", 5f); }

    Vector3 look = to - from; look.y = 0f;
    if (look.sqrMagnitude > 0.0001f) unit.transform.rotation = Quaternion.LookRotation(look);

    float t = 0f;
    while (t < duration)
    {
        t += Time.deltaTime;
        Vector3 next = Vector3.Lerp(from, to, Mathf.Clamp01(t / duration));
        if (cc != null) cc.Move(next - unit.transform.position);
        else unit.transform.position = next;
        yield return null;
    }
}
```

### 4-7. 이벤트 핸들러

```csharp
void OnQueueChanged(List<BattleUnit> queue)
{
    // 액션 바가 다음 N턴을 예측 표시할 수 있게 된 지점.
    // Destroy(list[0]) 방식과 달리 정렬된 AT 목록을 그냥 읽으면 된다.
    _actionBar.Render(_flow.Queue.Peek(12));
}

void OnSkillResolved(SkillResult res)
{
    for (int i = 0; i < res.Targets.Count; i++)
    {
        TargetResult tr = res.Targets[i];
        if (tr.Damage > 0) SpawnDamageText(tr.Target, tr.Damage, tr.Hit == HitResult.Critical);
        if (tr.Heal   > 0) SpawnHealText(tr.Target, tr.Heal);
        if (tr.Broken)     SpawnBreakEffect(tr.Target);
    }
}

void OnUnitDown(BattleUnit unit)
{
    // 큐에서는 이미 제거되었다. 연출만 남았다
    StartCoroutine(DeathRoutine(unit));
}

void OnBattleEnd(BattleOutcome outcome)
{
    Debug.Log(outcome == BattleOutcome.Win ? "승리" : "패배");
    // 결과 화면 → Field 복귀
}
```

## 5. CSV 컬럼 설명

### SkillData.csv

| 컬럼 | 설명 |
|---|---|
`index` | 스킬 고유 번호
`name` | 표시 이름
`owner` | 사용 가능 캐릭터 이름. `all` 이면 공용
`type` | `move` / `attack` / `item` / `guard` / `craft` / `art` / `scraft`
`power` | 위력 %. 100 = 공격력 그대로. 회복은 회복량 기준값
`costType` | `cp` / `ep` / `none`
`cost` | 소모량
`castDelay` | **아츠 캐스트 baseDelay.** 0 이면 캐스트 없이 즉시 발동
`baseDelay` | **발동 후 baseDelay.** 크래프트 20·25·30·40 / 아츠 15·20·25

기본 행동(이동 · 통상공격 · 아이템 · 방어)은 CSV 에 없다. `AT` 클래스의 상수를 기준으로 `SkillDataBase.BuildBasicActions()` 가 코드에서 만든다. 딜레이를 바꾸려면 `AT.BaseMove` 같은 상수를 고친다.
`targetSide` | `enemy` / `ally` / `self`
`targetShape` | `single` / `line` / `circle` / `all`
`range` | 사거리 (월드 유닛)
`area` | 범위 반경 · 직선 폭
`breakMult` | 브레이크 데미지 배율
`effectIds` | `SkillEffect.csv` id 목록. **`|` 로 구분** (콤마 금지)
`animTrigger` | Animator 트리거 이름

### SkillEffect.csv

`statName` 은 **`Stat` 프로퍼티 이름과 문자열이 정확히 일치**해야 합니다
(`Atk`, `Def`, `Speed`, `Ats`, `Adf` …). 이러면 효과 적용 코드를 스탯마다
`if` 로 분기하지 않고 한 곳에서 처리할 수 있습니다. `ItemStatus.csv` 와 같은 규칙입니다.

상태이상은 `statName` 에 이상 이름을 씁니다 — `Stun`, `Freeze`, `Poison`, `Seal`.

## 7. 남은 것

| 항목 | 상태 |
|---|---|

`ActionBar.Render(List<BattleUnit>)` | 액션 바 렌더러 구현 필요. `OnQueueChanged` 구독만 하면 예측 표시가 됩니다 |

쿼츠 (QPRM) | `SkillResolver.CalcDamage` 의 `qprm` 인자로 열어 두었습니다. 오브먼트 구현 시 전달 |
